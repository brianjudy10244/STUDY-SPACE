# STUDYSPACE — 나만의 학습 리듬

React · TypeScript · Vite로 구현한 학습 관리 프런트엔드입니다. 프로젝트의 Milky Season 팔레트를 참고해 세이지·크림 배경과 과목별 파스텔 색상을 적용했습니다.

## 웹에서 보기

[STUDYSPACE 실행하기](https://brianjudy10244.github.io/STUDY-SPACE/)

## 실행

macOS에서는 프로젝트 폴더의 `STUDYSPACE.command`를 더블클릭하면 로컬 서버와 브라우저가 자동으로 열립니다. 처음 실행할 때 macOS가 차단하면 파일을 우클릭하고 `열기`를 선택하세요.

터미널에서 직접 실행하려면 다음 명령을 사용합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소(기본 http://localhost:5173)를 엽니다.

```sh
npm run build  # 타입 검사와 프로덕션 빌드
npm run test   # 추천, 날짜, 충돌 계산 테스트
npm run preview
```

## 기능

- 주간 / 월간 캘린더, 기간 이동, 오늘 이동, 과목별 표시 필터
- 학습 일정 추가·수정·삭제, 겹치는 시간 검증
- 완료 여부, 집중도 1–5점, 학습 메모 기록
- 학습 시간, 완료 수, 평균 집중도, 주간 목표 달성률
- 일별·과목별 학습 통계 및 검색 가능한 학습 기록
- 추천 시간을 캘린더에 추가, 주간 목표와 선호 시간 설정
- localStorage 저장, JSON 내보내기, 샘플 데이터 제거
- 반응형 UI, 키보드 포커스, 모달 포커스 제한 및 Escape 닫기

## 추천 기능과 데이터

현재 AI 플래너는 외부 AI API를 호출하지 않는 **규칙 기반 프리뷰**입니다. 완료한 학습의 시간대별 평균 집중도를 계산하고 향후 7일의 선호 시간 중 기존 일정과 겹치지 않는 60분 구간을 추천합니다. 기록이 적으면 선호 시간 내 빈 시간을 안내합니다. 실제 AI 모델의 예측이나 의학적 집중력 평가가 아닙니다.

처음 실행하면 현재 주의 샘플 데이터가 표시됩니다. 상단의 `샘플 지우기`는 샘플만 제거하며 직접 추가한 일정은 유지합니다. 정보는 현재 브라우저의 `studyspace.study.v1`에 저장됩니다. 기존 `pln.study.v1` 데이터가 있으면 처음 실행할 때 자동으로 이어받습니다. 계정, 서버 저장, 기기 간 동기화는 아직 연결되지 않았습니다. 브라우저 데이터를 지우면 기록이 삭제되므로 필요하면 학습 기록 화면에서 JSON을 내보내세요.

학습 일정은 기기의 로컬 날짜/시간 기준이며 08:00–22:00 범위를 지원합니다. UI의 시간대 표기는 한국 사용 환경(GMT+9)을 기본으로 합니다. 실제 서비스에서는 계정별 시간대를 명시적으로 처리해야 합니다. 폰트는 Google Fonts를 사용하며 연결되지 않으면 시스템 폰트로 표시됩니다.

## 주요 파일

- `src/App.tsx`: 화면, 일정 편집, 학습 기록, 설정
- `src/planner.ts`: 데이터 모델, 날짜 계산, 시간 충돌 검증, 추천
- `src/styles.css`: 디자인 토큰과 반응형 스타일
- `src/planner.test.ts`: 핵심 계산 로직 검증

후속 개발에서는 인증·데이터베이스·동기화와 실제 AI 추천 API를 연결할 수 있습니다. API 키는 프런트엔드에 넣지 않고 서버에서 관리해야 합니다.
